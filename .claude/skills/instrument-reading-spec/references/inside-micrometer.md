# 내측마이크로미터

수업 방식에 두 종류가 있으므로 명세에서 옵션으로 둔다. 기본값은 **캘리퍼형**.

## 캘리퍼형 (기본)
- 범위 예: 5~30mm (기본 5mm 오프셋 시작), 분해능 0.01mm
- 슬리브/심블 눈금 구조와 읽는 방향이 외측마이크로미터와 같다 (조(jaw)가 벌어질수록 숫자 증가).
- 정답 = 외측마이크로미터 읽기 규칙 결과 + 범위 시작값(오프셋) — 오프셋 처리를 명확히 표시.

## 단봉형(로드형, 선택 옵션)
- 슬리브 눈금의 숫자 증가 방향이 심블 쪽에서 반대(역방향 눈금). 연장봉 길이는 별도로 더한다.
- 정답 = 연장봉(또는 기본) 길이 + 슬리브/심블 읽기 (역방향 해석 주의).
- **수업에서 쓰는 형식이 불확실하면 구현 전에 사용자에게 확인 요청 → 명세 "확인 필요"에 기재.**

## 공통
- 설명문에 오프셋/연장봉 길이를 별도 항으로 표시: "범위 시작 {O}mm + 슬리브 … + 심블 … = {값}mm"
- 학생이 외측과 혼동하지 않도록 화면에 "내측" 배지와 측정면이 안쪽을 향하는 모양을 그린다.
