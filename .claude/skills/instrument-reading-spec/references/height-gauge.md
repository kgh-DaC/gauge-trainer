# 하이트게이지

- 범위: 0~300mm (기본), 부척 옵션과 읽기 규칙은 버니어캘리퍼스와 동일
  - 1/50mm형(기본, 분해능 0.02mm) / 1/20mm형(0.05mm)
- 본척은 세로(수직), 슬라이더(부척 포함)가 위아래로 움직인다. 스크라이버(금긋기 날) 높이가 측정값의 기준이다.
- 읽기: 정답 = 부척 0점 바로 아래의 본척 눈금(정수 mm) + 일치하는 부척 선 번호 × 분해능
  - 방향 주의: 본척 숫자는 아래에서 위로 증가한다. "0점 바로 아래" 눈금을 읽는다 (캘리퍼스는 "왼쪽").
- 상태변수: y = 슬라이더 위치(1/100mm 정수). 스냅은 분해능 배수.
- 스크라이버 옵셋(스크라이버 두께 기준면)은 기본 0으로 두고 옵션으로 둔다. 옵션 켜면 설명문에 "- 옵셋 {값}" 항을 추가.
- 설명문: "본척 {M}mm + 부척 {n}번째 선 × {res}mm = {값}mm"
- 화면은 세로 긴 형태이므로, 전체 높이(300mm)를 보여주지 않고 슬라이더 주변을 확대해 보여주는 "확대 창"을 둔다(드래그는 전체 축에서).
