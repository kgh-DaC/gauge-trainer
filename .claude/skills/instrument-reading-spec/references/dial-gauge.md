# 다이얼게이지

- 분해능 0.01mm (옵션: 0.001mm형, 기본 꺼짐), 측정 범위 기본 0~10mm
- 큰 바늘: 원주 100등분, 1바퀴 = 1mm, 1눈금 = 0.01mm
- 작은 바늘(회전수 계): 큰 바늘이 1바퀴 돌 때마다 1눈금(1mm) 이동, 0~10
- 베젤(다이얼 테두리)은 돌려서 0점을 맞춘다. 문제 유형 2가지
  1. 절대 읽기: 베젤 0점 고정, 작은 바늘 정수 mm + 큰 바늘 눈금 × 0.01
  2. 영점 이동: 학생이 베젤을 돌려 임의로 영점을 맞춘 뒤 읽는 연습 (옵션)
- 상태변수: s = 스핀들 변위(1/100mm 정수, 0~1000). 큰 바늘 각 = (s mod 100)/100 × 360°, 작은 바늘 = floor(s/100)
- 정답 = s × 0.01mm = (작은 바늘 mm) + (큰 바늘 눈금) × 0.01
- 학생 입력: 큰 바늘을 드래그하면 바늘이 회전하고 s가 연속 갱신(바늘이 한 바퀴 넘어가면 작은 바늘이 증가/감소). 0 아래, 10mm 위로는 제한.
- 설명문: "작은 바늘 {A}mm + 큰 바늘 {n}눈금 × 0.01 = {값}mm"
- 경계 출제: 큰 바늘이 0 근처(99↔0 넘어가는 지점)일 때 작은 바늘 판독 오류가 잦다 → s = 99, 100, 101, 199, 200 포함.
- 우리나라 KS 규격에 눈금 숫자가 시계방향 증가인 일반형 + 역방향(밸런스형) 있음 → 기본은 일반형(시계방향 0→100).
