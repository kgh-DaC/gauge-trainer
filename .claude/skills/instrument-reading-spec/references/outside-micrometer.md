# 외측마이크로미터

- 범위: 0~25mm, 분해능 0.01mm (옵션: 슬리브에 부척이 있는 0.001mm형 — 기본 꺼짐)
- 슬리브(스리브) 기선 위쪽: 1mm 눈금(5mm마다 숫자), 아래쪽: 0.5mm 눈금 (위 눈금 사이 중간)
- 심블(딤블): 원주 50등분, 1눈금 = 0.01mm, 한 바퀴 = 0.5mm
- 읽기: 정답 = 슬리브 1mm 눈금(노출된 마지막 눈금) + (0.5mm 눈금이 노출되었으면 0.5) + 심블 기선과 일치하는 눈금 × 0.01
- 상태변수: p = 심블 앞단 위치(1/100mm 정수, 0~2500). 심블 회전각 = (p mod 50)/50 × 360°
  - 슬리브 노출: floor(p/50) × 0.5mm 까지 노출 → 1mm 눈금 = floor(p/100), 0.5 눈금 여부 = floor(p/50) mod 2
  - 심블 읽음 = p mod 50
- 주의: 0.5mm 눈금이 노출되었는데 심블 값이 0.49 근처인 경계에서 학생이 흔히 틀린다 → 경계값(p = 49, 50, 51, 99, 100 …)을 출제 풀에 포함.
- 설명문: "슬리브 {A}mm + {0.5 또는 0}mm + 심블 {n}×0.01mm = {값}mm"
- 인터랙션: 심블을 세로로 끌어(또는 휠) 좌우로 이동. 드래그는 회전이 아니라 p의 증감으로 단순화하되 심블 눈금은 회전하는 것처럼 이동 표시.
