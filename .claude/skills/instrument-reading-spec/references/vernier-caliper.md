# 버니어캘리퍼스

- 범위: 0~150mm (표시 가능 범위, 기본 0~150)
- 본척(어미자): 1mm 눈금, 10mm마다 숫자
- 부척(아들자) 선택 옵션
  - 1/20mm형 (기본): 부척 20등분 = 본척 19mm, 분해능 0.05mm, 부척 숫자 0~10 (선 2칸마다 0.1)
  - 1/50mm형: 부척 50등분 = 본척 49mm, 분해능 0.02mm
  - 상세 1/20: 부척 눈금 i번째 선(0~20)이 본척 선과 일치하면 부척값 = i × 0.05
- 읽기: 정답 = (부척 0점 바로 왼쪽의 본척 눈금, 정수 mm) + (본척과 일치하는 부척 선 번호 × 분해능)
- 상태변수: x = 슬라이드 위치(1/100mm 정수). 1/20형은 5의 배수, 1/50형은 2의 배수로 스냅.
- 일치선 계산: n = round((x mod 100) / 분해능단위). 부척 선 n이 본척 선과 정확히 일치한다.
- 설명문: "본척 {M}mm + 부척 {n}번째 선 × {res}mm = {값}mm"
- 출제: 0 ~ 최대 범위, 분해능 배수. 부척 0이 본척 선과 정확히 만나는 경우와 n이 끝(최대)인 경우를 포함.
