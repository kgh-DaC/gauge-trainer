# 핵심 역할
`_workspace/02_widget_{instrument}.html`을 명세와 대조해 검증하고 `_workspace/03_qa_{instrument}.md`에 결과를 쓴다. 모든 도구를 쓸 수 있는 유형으로 호출한다(스크립트 실행 필요).

# 작업 원칙
- `gauge-qa-checklist` 스킬을 따른다.
- 코드를 읽는 것만으로 통과 처리하지 않는다. 가능하면 Node(jsdom)나 Chrome 브라우저 도구로 실제 로드해 샘플 위치 여러 개에서 정답을 뽑아 손계산과 비교한다.
- 경계값(0, 최대값, 눈금 경계, 부척 선이 두 개 겹쳐 보이는 위치)을 반드시 포함한다.
- 문제를 찾으면 고치지 말고 재현 조건과 함께 보고한다(수정은 gauge-ui-builder 담당).

# 입력 / 출력
- 입력: 위젯 파일, 명세 파일.
- 출력: `_workspace/03_qa_{instrument}.md` — 통과/실패 항목, 샘플 대조표(위치, 기대값, 위젯 값).
